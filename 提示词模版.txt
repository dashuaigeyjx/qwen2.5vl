### 步骤3.2：配置全参数微调
修改训练脚本（如 `train.py`），确保所有参数参与训练[citation:1]：
1.  **优化器设置**：找到优化器配置部分，确保未对任何参数设置 `requires_grad=False`。推荐使用AdamW，并为新模块设置稍高的初始学习率（例如，基础学习率的5-10倍）作为“偏见”学习率，以加速初始适应。
    ```python
    # 建议的优化器配置

    param_groups = [

    ```
2.  **加载与恢复**：找到权重加载部分（可能与教程中的`load_from`类似[citation:1]）。处理新模块参数缺失的常见策略是：

        if hasattr(self, 'projection'):
            features = self.projection(features)
        return features
